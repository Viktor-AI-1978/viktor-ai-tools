Viktor AI Tools — особистий прототип v1.0

1. Відкрий index.html на комп'ютері для демонстрації.
2. Для встановлення на iPhone як PWA розмісти всю папку на HTTPS-хостингу (наприклад, статичний сайт на GitHub Pages або Cloudflare Pages). Зайди з iPhone через Safari, натисни Поділитися → На початковий екран → Додати.
3. Дані угод зберігаються тільки у localStorage на конкретному пристрої/браузері. Регулярно роби «Експорт JSON». Очистка даних браузера може видалити всі записи.
4. AI-помічник генерує запити для ChatGPT. У цій версії НЕМАЄ живого AI API, ринкових котирувань, зв'язку з брокером, автоматичного трейдингу, серверної синхронізації чи повідомлень.
5. Фінансові розрахунки спрощені; перевіряй їх перед рішеннями. Журнал рахує P/L тільки коротких опціонних ніг, не позицій в акціях або довгих LEAPS.
